# Third-party material

What the repo carries that was written elsewhere, and under what terms.

## Anthropic frontend-design skill

`.claude/skills/frontend-design` is the skill as published at github.com/anthropics/skills, Apache License 2.0 (the licence is in the folder). Claude Code reads it when it builds this app's own screens. `packages/shared/src/design-craft.ts` is an adaptation of it for the phone-app prompts the Workshop runs at run time: shortened, turned to the phone, and its two passes mapped onto the brief and the page. The writing rules are kept whole.

## UI/UX Pro Max tables

`packages/shared/src/studio/tables.ts` is generated by `tools/studio-tables.py` from three data files of github.com/nextlevelbuilder/ui-ux-pro-max-skill (MIT, Copyright (c) 2024 Next Level Builder): `products.csv` (192 product types with the words that point to them, the styles that suit them and their page patterns), `colors.csv` (a semantic palette per product type) and `typography.csv` (74 font pairings with their moods). The studio reads a founder's words against them to draw the product without a model, and hands the same plan to the model as the design system to build on. The rest of that project (its scripts, its other tables) is not used.

Type on generated pages is loaded from Google Fonts (fonts.googleapis.com) with system fallbacks; each family carries its own licence (all open, mostly SIL OFL) and is not redistributed here.
